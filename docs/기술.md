# 기술

무엇으로 만들고, 그림을 어떻게 뽑아 게임에 넣는지. 그림 크기 기준은 → `아트_규격.md`, 게임 내용은 → `기획.md`.

## 1. 만드는 것
- **브라우저 게임**: HTML + JavaScript 한 페이지. 서버 없음. PC는 더블클릭으로 열림, 휴대폰은 인터넷에 올려서 연다.
- **휴대폰이 기본, 태블릿 · PC 웹에서도 다 할 수 있게 열어 둔다. 가로 화면.** 화면 크기에 따라 배율만 달라지고 조작은 같다(누르기 = 터치 · 마우스). 세로로 들면 「가로로 돌려 주세요」.
- **조작 — 누르기 + 긋기**: 칸을 누르면 남편이 걸어가서 그 칸에 맞는 일을 한다. 여러 칸을 손가락으로 그으면 차례로 돈다. PC는 마우스로 똑같이. 버린 안: 왼쪽 아래 조이스틱 + 오른쪽 아래 실행 버튼 — 걷는 손맛은 좋지만 칸마다 버튼을 눌러야 해 반복이 늘고, 저녁 서빙(손님 누르기)과 방식이 섞이고, 이 게임의 재미는 걷기보다 고르기라서.
- **칸은 손가락 크기 이상으로**: 화면에서 한 칸이 최소 44px(애플이 권하는 누르는 곳 최소 크기 44pt). 맵이 한 화면에 안 들어오면 화면이 남편을 따라간다.
- **엔진 없이 기본 캔버스로**: 땅(듀얼 그리드) · 글자 데이터 그림 · 경영 규칙은 어느 엔진에도 없어 어차피 직접 짠다. 무거워지면 그리는 부분만 PixiJS로 갈아 끼울 수 있게 나눠 둔다. 살펴본 것: Phaser(무난한 대안) · PixiJS(그리기 전용) · PixelJS(0.0.5, 저장 기능이 아직 없어 보류).
- **코드는 범용으로 한 번, 콘텐츠는 데이터로**: 시스템(땅 상태 · 성장 · 창고 · 손님 등)은 콘텐츠를 모르고 데이터만 읽는다. 새 작물 · 메뉴 · 물건 = 그림 + 데이터 한 줄(`data/*.js`). 크기 예외도 데이터로(→ `아트_규격.md` 3).
- **그림은 글자 데이터로**: PNG를 `sprites/*.js`(글자 하나 = 픽셀 하나 + 팔레트)로 바꿔 JS가 캔버스에 그린다. 색 바꾸기 · 반전은 그릴 때.
- **이동**: 위치는 화면 픽셀 단위로 옮겨 부드럽게(게임 픽셀 단위면 느린 속도에서 뚝뚝 끊김). 대각선은 x · y 소수점을 맞춰 두 축이 같은 프레임에 움직이게(안 그러면 계단처럼 버벅임). 그림과 그림자는 같은 발 위치를 쓴다.
- **방향**: 처음엔 4방향(아래 · 오른쪽 · 위 · 왼쪽), 대각선으로 가면 옆을 봄. 8방향은 그림 + 방향 목록만 늘리면 됨(이동 코드는 그대로).
- **땅 그리기 — 듀얼 그리드**: 화면 칸을 반 칸 밀고, 칸의 네 모서리 = 주변 네 땅의 상태. 경계가 이어지는 16칸 타일셋 하나로 어떤 모양이든 자연스럽다.
- **젖은 땅**(지금은 안 씀 — 물 주기 없음 → `기획.md` 5. 비 오는 날 등에 쓸 때를 위해 남겨 둠): 따로 뽑은 타일을 덮으면 결이 달라 어색함 → 그 칸의 흙 픽셀만 어둡게(잔디 제외, 마른 쪽 가장자리는 덜 어둡게, 붙은 젖은 칸끼리는 이어짐).

## 2. 그림 뽑는 도구
누가 무엇을 뽑는지는 → `아트_규격.md` 4.
- **Retro Diffusion**: 충전금(API 잔액)으로 씀. MCP `retrodiffusion`(이 폴더 전용) + `tools/rd_gen.py`(API 직접). 이미지가 들어가는 요청은 MCP로 base64를 옮겨 적다 깨질 때가 있어서 API 직접이 안전. 가격(64×64 기준): rd_fast $0.03 · rd_plus $0.06 · rd_pro $0.18, 타일셋 $0.10, 타일 · 물건 장당 $0.06. 가격만 보기(`"check_cost": true`)는 무료.
- **PixelLab**: 체험판(동시 1장, 생성 횟수 적음, `get_balance`). MCP `pixellab`(이 폴더 전용). 캐릭터 전용.
- 둘 다 **생성 전에 비용을 알리고 묻는다.**
- 키는 `.env`(`PIXELLAB_API_KEY` · `RETRODIFFUSION_API_KEY`, 깃 제외). 키를 바꾸면 `.env`와 MCP 등록(`claude mcp remove <이름> -s local` 후 다시 add) 둘 다. 다른 파일엔 키를 적지 않는다.

## 3. 도구 파일
- `tools/rd_gen.py`: Retro Diffusion 생성. `python tools/rd_gen.py 출력.png '{"prompt": "...", "prompt_style": "...", "width": 16, "height": 16}'` — 여러 장이면 `_0`, `_1`…, 생성 정보는 `.json`.
- `tools/png_to_sprite.py`: PNG → 글자 데이터(줄이기 · Resurrect 64 색 맞춤 · 외곽선 다시 긋기, 여러 프레임은 공통 영역으로 1:1). 캐릭터용. 환경 그림은 원래 색을 쓰므로 색 맞춤을 끄고 쓴다(→ `아트_규격.md` 5).
- `tools/make_farm_assets.py`: 타일셋 → 듀얼 그리드용 데이터 변환 **예시**. 32px · 4×5칸 시절 것이라 16px 규격에 맞게 고쳐 쓴다(입력이던 밭 그림은 보관 파일에).
