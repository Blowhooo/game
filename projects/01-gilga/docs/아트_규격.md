# 아트 규격

그림 · 판정의 크기 기준, 누가 무엇을 뽑는지, 그림에 대해 배운 것. 그림(에셋)은 이 규격에 맞춰 새로 뽑고, 코드는 규격과 데이터만 읽는다(→ `기술.md` 1).

## 1. 세 가지 크기를 따로 정한다
| 개념 | 뜻 |
|---|---|
| **격자(타일)** | 맵의 기본 칸. 땅 상태 · 물건 놓는 자리 · 이동 판정의 기준. **16×16** |
| **그림(스프라이트)** | 화면에 그리는 크기. 격자보다 커도 되고, 넘치는 쪽은 **위**. |
| **차지하는 자리(풋프린트) · 판정(히트박스)** | 실제로 바닥을 차지하고 부딪히는 면적. 그림보다 작고 **발밑 · 밑동**만. |

모든 것을 같은 크기(32×32)로 그리면 사람과 물건이 똑같아 보여 어색하고, 물건 그림만 줄이면 판정이 애매해진다 → 그림과 판정을 분리한다(스타듀 밸리가 쓰는 원리).

## 2. 종류별 기본값
| 종류 | 그림 | 차지하는 자리 | 예 |
|---|---|---|---|
| 사람 | 16×32 (필요하면 가로 24까지) | 발밑 1칸, 판정은 그보다 조금 작게 | 부부 · 손님 |
| 작은 물건 | 16×16 | 1칸 | 돌 · 자루 · 음식 아이콘 |
| 키 큰 물건 | 16×32 | 바닥 1칸 | 작물 · 상자 · 등불 · 간판 |
| 나무 | 32×48 ~ 48×80 | 밑동 1~2칸 | |
| 건물 | 격자의 배수 | 바닥 몇 칸(문 자리는 비움) | 식당 · 창고 |

- **기준점**: 그림의 아래 가운데(발 · 밑동)를 칸에 맞춘다.
- **그리는 순서**: 바닥(기준점)의 y가 작은 것부터 → 앞에 선 것이 위에 그려진다(나무 뒤로 가면 가려짐).
- **시점**: 탑다운 3/4(위에서 비스듬히). 모든 그림이 같은 시점.
- **화면 배율**: 정수 배율(픽셀이 흐려지지 않게). 몇 배인지는 화면 크기와 손가락 크기로 정해진다(→ `기술.md` 1).

## 3. 예외는 데이터로
물건마다 크기를 데이터에 적고, 없으면 종류 기본값을 쓴다. 코드는 숫자만 읽는다 — "이 물건이면" 하고 코드로 골라 처리하지 않는다.
```js
tall: { sprite: [16, 32], footprint: [1, 1] },                                   // 종류 기본값
scarecrow: { kind: 'tall' },                                                       // 그대로
pumpkin_giant: { kind: 'tall', sprite: [32, 32], footprint: [2, 2] },             // 이 물건만 크게
well: { kind: 'building', sprite: [32, 48], footprint: [2, 1], hitbox: [2, 4, 28, 12] }, // 판정 직접 지정
```
코드를 고치는 건 **새로운 행동**(움직이는 장애물 · 올라타기 등)이 생길 때뿐. 그때도 그 물건 전용이 아니라 기능 하나를 만들고 데이터로 켠다.
