# 그림 도구 (모든 게임 공용)

그림을 뽑는 도구 · 가격 · 키, 누가 무엇을 뽑나, 그림에 대해 배운 것. 게임마다 다른 크기 · 규격은 그 게임의 `docs/아트_규격.md`.

## 1. 도구 · 가격 · 키
누가 무엇을 뽑는지는 → 3.
- **Retro Diffusion 3D(로우폴리)**: 픽셀 무늬를 입힌 각진 3D 모델 생성 · 동작 붙이기. 모델 하나 생성 Lite $0.10 · 보통 $0.25(16)~$3(256), 동작 붙이기 $0.08~1. 가격은 `get_lowpoly_pricing`(무료)
- **Retro Diffusion**: 충전금(API 잔액)으로 씀. MCP `retrodiffusion`(이 폴더 전용) + `shared/tools/rd_gen.py`(API 직접). 이미지가 들어가는 요청은 MCP로 base64를 옮겨 적다 깨질 때가 있어서 API 직접이 안전. 가격(64×64 기준): rd_fast $0.03 · rd_plus $0.06 · rd_pro $0.18, 타일셋 $0.10, 타일 · 물건 장당 $0.06. 가격만 보기(`"check_cost": true`)는 무료.
- **PixelLab**: 체험판(동시 1장, 생성 횟수 적음, `get_balance`). MCP `pixellab`(이 폴더 전용). 캐릭터 전용.
- 둘 다 **생성 전에 비용을 알리고 묻는다.**
- **바깥 무료 3D 모델(참고)**: Meshy 갤러리의 Structure 모델은 페이지에 CC0(상업 사용 · 출처 표기 없이)로 적혀 있음. 받으려면 무료 계정 필요, 받는 횟수 제한은 페이지에 없음(무제한이라는 말도 없음). 대부분 실사풍이라 픽셀 캐릭터와 그림체가 안 맞을 수 있음 — 받아 보고 판단. 아직 안 받아 봄
- 키는 `.env`(`PIXELLAB_API_KEY` · `RETRODIFFUSION_API_KEY`, 깃 제외). 키를 바꾸면 `.env`와 MCP 등록(`claude mcp remove <이름> -s local` 후 다시 add) 둘 다. 다른 파일엔 키를 적지 않는다.

## 2. 도구 파일
- `shared/tools/rd_gen.py`: Retro Diffusion 생성. `python shared/tools/rd_gen.py 출력.png '{"prompt": "...", "prompt_style": "...", "width": 16, "height": 16}'` — 여러 장이면 `_0`, `_1`…, 생성 정보는 `.json`.
- `shared/tools/pixellab_sheet.py`: PixelLab 캐릭터 내려받기(zip을 푼 폴더) → 한 장 그림 PNG + 자리표 JS(`SHEETS[이름]`). `python shared/tools/pixellab_sheet.py <푼 폴더> <출력 폴더> <이름> [칸=48]`. 내려받기는 `get_character`의 download 주소에 키를 붙여(`Authorization: Bearer`) 받는다
- `shared/tools/png_bundle.py`: PNG 여러 장 → JS 한 파일(`window.IMGDATA`). 브라우저에서 파일을 바로 열면 3D(WebGL)가 바깥 그림을 못 읽어서 씀. `python shared/tools/png_bundle.py <출력.js> <png...>`
- `shared/tools/png_to_sprite.py`: PNG → 글자 데이터(줄이기 · Resurrect 64 색 맞춤 · 외곽선 다시 긋기, 여러 프레임은 공통 영역으로 1:1). 캐릭터용.

## 3. 누가 무엇을 뽑나
- **캐릭터 · 동작 = PixelLab, 사용자가 직접**(크레딧은 캐릭터에만). 크기 32로 만들면 32×32 캔버스 안에 사람 → 16×32에 맞춰 자른다. Claude는 받은 PNG를 데이터로 바꿔 붙인다.
- **사물 · 환경 = Retro Diffusion, Claude가**: 타일 · 작물 · 아이템 · 나무 · 건물 · UI · 이펙트. 타일은 16, 물건은 2의 표 크기로 지정. PixelLab으로 사물을 뽑지 않는다.
- **인물 원화 · 대화창 얼굴 = 제미나이, 사용자가 직접.** 인물마다 기본 그림(전신 · 평온한 얼굴) 한 장으로 생김새를 확정 → 그 그림을 기준으로 표정(상반신)을 한 장에 모아 뽑는다. 그림체를 맞추려고 공통 문구를 매번 앞에 붙인다
  - 원화 비율은 5등신쯤(첫 주인공 그림 기준). 게임 속 픽셀 인물(16×32)은 따로 줄여 그린다
  - 표정은 한 장에 3개(1×3) — 6개를 한 장에 넣으니 전신으로 그려져 얼굴이 너무 작았다. 얼굴만(상반신) 뽑으면 얼굴이 갸름 · 젊게 바뀌었다(주인공) → 허리 위(어깨 · 배까지) + 「같은 얼굴(둥근 얼굴 · 나이 · 수염) 유지」 문장을 넣어 다시 볼 것

## 4. 배운 것
- **캐릭터 동작**: PixelLab이 확실히 잘함(뼈대 동작 틀). 다만 template 동작은 캐릭터를 새로 그려 얼굴 · 크기가 바뀜(skeleton 방식은 유지되지만 움직임이 작음). Retro Diffusion 동작은 캐릭터 유지는 좋지만 팔다리 · 도구 · 무게중심이 엉성하고, 발을 크게 그려 탑다운 시점이 깨지기도 함. Claude가 픽셀 조각을 옮겨 붙여 고치면 갈수록 깨짐.
- **PixelLab 동작마다 발 위치가 다르다**: 밀짚모자 소녀(48)는 멈춘 모습 발끝이 46줄, 걷기는 42줄 → 그대로 쓰면 걸을 때 떠 보인다. `pixellab_sheet.py`가 동작마다 발끝을 맞춘다
- **Retro Diffusion이 잘하는 것**: 경계가 이어지는 타일셋 · 타일 위 물건 · 아이템 모음 · UI · 이펙트 · 배경 · 잔잔한 움직임(작물 흔들림).
- **도구 · 물건 요청**: 이름만 쓰면 무기 · 판타지 물건으로 그림(괭이 → 전투용 낫). 직업 · 세계관에 맞는 생활 도구로, 모양 · 재질 · 크기 · "무엇이 아닌지"까지 적는다. 쓸 때 · 들고 다닐 때 쥐는 손(한 손 · 두 손)도 따로.
- **타일셋을 여러 벌 뽑으면 잔디 색이 벌마다 다르다**(잔디↔밭 · 잔디↔길을 따로 뽑으니 하나는 탁한 초록, 하나는 밝은 연두) → 기준 잔디 한 칸을 잘라 `rd_tile__tileset_advanced`의 그림으로 넣어 다시 뽑으면 거의 맞고, 남는 미세한 차이는 타일셋의 잔디를 투명으로 해 없앤다(길가식당 `tools/art_to_js.py`).
- **밭 흙**: 「tilled soil」만 쓰면 벽돌 무늬가 나온다 → 「부드러운 흙 · 가로 이랑 · 벽돌 아님 · 돌 아님」처럼 무엇이 아닌지까지 적는다. 그래도 이랑 줄무늬는 아직 약하다.
- **색**: 환경 그림을 Resurrect 64로 맞추면 잔디가 청록, 흙이 붉게 탁해짐 → 원래 색 그대로 쓴다.
